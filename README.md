## 笔记约定

1. 每天一篇 `notes/YYYY-MM-DD.md`，按时间线写，重点记**走错的路**
2. 每篇至少一句"我原来以为…其实…"，没有这句说明当天没真正想通
3. 真故障进 `notes/故障案例库.md`，编号顺延
4. 每月最后一天写一份月度复盘，并更新 `notes/INDEX.md`

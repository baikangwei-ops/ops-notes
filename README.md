## 目录

```
ops-notes/
├── README.md            仓库说明与里程碑
├── notes/
│   ├── YYYY-MM-DD.md    每日学习日志，一天一篇
│   ├── 故障案例库.md     真实报错的排查过程（现象→排查→根因→修法）
```

这个仓库只放**能给别人看的产出**：每日日志、真实故障记录、可运行的脚本。
练习作业、个人知识卡片、课程随堂笔记不放在这里——那些留在本地自己用。

# 2026-11-26 · D4

前三天都在自己电脑上折腾 git，今天终于碰到"云"了。计划上 D4 只有四行字：实名认证、起一台 2C2G 的 ECS、安全组只放行 22、ssh 登录。我以为半小时能收工，结果中间自己把服务器关机了，又学了一课。

领机器比装 VMware 快十倍。支付宝扫码实名两分钟过审，然后进试用中心，有 ECS（300 元额度，3 个月）和轻量应用服务器（1 个月，1G 内存）两个选择。选了 ECS——轻量服务器是建站套餐，预装宝塔面板、WordPress，面板把底层操作全包住，我练的就是底层，不能用它。规格页有列价格，我一开始想选配置高的，后来看明白一件事：额度是固定的 300 元，单价越低能用的时间越长。2核2G 经济型 e 是 ¥0.123/小时，能撑约 2439 小时，最高的那档 ¥0.731/小时只剩 410 小时，同样 300 元差六倍时长。最后选北京地域（离郑州最近）+ 2核2G + 40G ESSD + CentOS 7.9（和班级一致），预装应用那四个一个没勾。创建完弹了个安全防护权益领取，云备份加主机病毒防护，我都关了——云备份会代替我练明天的快照，病毒防护会在 2G 内存的机器上常驻一个 agent 添乱。学习机只装自己手动装的软件。

安全组是云和本地最大的一个区别。本地 VMware 装完系统 ssh 直接就能连，云上默认所有端口都关着，门得自己开。加规则时纠结协议选"所有 TCP"还是"自定义 TCP"，最后改成后者加端口 22/22，理由是想明白了一条原则：需要哪个端口开哪个，公网上有扫描器 24 小时扫全网，新 IP 几分钟就会被扫到，"所有 TCP + 全部端口"等于把机器所有的门朝外敞开。描述栏认真写了"ssh 远程登录"，以后端口多了这张规则表就是端口台账。

登进去的过程很顺：`ssh root@112.126.89.92`，首次连接弹主机指纹确认敲 yes（D1 学的 known_hosts 第三次见面），输密码时屏幕上什么都不显示、连星号都没有——这是 Linux 的老规矩，密码输入过程对旁观者完全保密——盲打完回车就进去了。提示符从我自己电脑的名字变成 `[root@iZ2ze... ~]#`，那一刻挺奇妙的：人在郑州，敲的命令跑在北京机房的机器上，这就是"云"的全部含义。

然后我把这台服务器关了。

按 Linux 的老习惯改完主机名想验证效果，我用的是 `poweroff` 不是 `reboot`。机器直接关机，终端"卡死"在那里不动。我以为终端坏了，关掉重开，ssh 报 `Connection timed out`。第一反应是安全组配错了（毕竟刚学超时等于端口不通），查了一圈规则都是对的，最后回控制台一看——实例状态：已停止。原来"卡死"不是故障，终端还开着，但对面的机器已经没了。本地 VMware 关机后窗口还在，点一下"开启此虚拟机"就活了，所以从来没觉得 poweroff 有什么风险；云上没有那个窗口兜底，机器停了就是停了，必须回控制台手动启动。想重启用 `reboot`，掉线一分钟自己回来，`poweroff`、`shutdown -h now`、`init 0` 都是关机，只有当天彻底收工才用。

控制台点"启动"，等状态变回运行中，再 ssh 进去了，`hostname` 显示我改的新名字——说明改主机名重启生效这个习惯本身没错，错的只是关机方式。跑了勘察四连：

```
hostname                 # 新主机名，生效了
uname -r                 # 3.10.0-1160.el7.x86_64 → 内核 3.10，el7 体系，64 位
cat /etc/redhat-release  # CentOS Linux release 7.9.2009
lsblk                    # vda 40G，vda1 挂 /
free -h                  # total 1.8G，Swap 0B
```

三个和本地不一样的地方：盘叫 vda 不叫 sda（v 是 virtio 云盘高速通道，s 是 SCSI 模拟传统硬盘，同一个 lsblk 两种命名暴露底层虚拟化技术的不同）；2G 内存显示 1.8G（内核和硬件预留吃掉一点，正常）；Swap 是 0B（云镜像默认不开，意味着内存一满直接触发 OOM Killer，没有 swap 缓冲——D2 口述的 OOM Killer 在这台机器上是"没有安全垫"的版本）。顺便把 free 的输出读懂了：free 那列很小不代表内存不足，内核会拿空闲内存做磁盘缓存（buff/cache），真正能用的看 available，"free 只剩 100M 是不是要爆了"是面试高频陷阱题。

今天真正长进的认知，是几条从坑里抠出来的东西。实例不是什么新发明，就是云上的虚拟机——阿里云从机房物理机上切出一块，装上系统配个公网 IP，这个跑起来的独立小服务器就叫实例，本地虚拟机、ECS 实例、数据库实例、Redis 实例都一样，共同点是从大资源池切出来、能创建能销毁。停止不等于释放：停止只是关机，资源还占着、额度还在扣（0.12 元/小时），释放才是真删。额度思维：试用给的是钱不是时间，所以选单价最低的规格，用时长换自由度。还有一条更根本的——云运维不是"ssh 敲命令"一件事，今晚做的只是主机层，完整的还有资源层（控制台管 VPC、安全组、SLB、RDS）、可观测层（监控告警）、自动化层（脚本/Ansible/流水线/K8s），计划正好按这个顺序排到 3 月。

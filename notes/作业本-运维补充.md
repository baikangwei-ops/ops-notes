## 三、任务清单（6 步，按顺序做）

### 步骤 1 · 建目录树（3 分钟）

**做什么**：建 `/tmp/prj`，内含 `src/main`、`docs`、`backup`

```bash
mkdir -p /tmp/prj/src/main /tmp/prj/docs /tmp/prj/backup
ls -R /tmp/prj
```

**预期输出**：能看到 `src` → `main` 两级嵌套 + `docs` + `backup`

**✅ 自检**：`-p` 是干什么的？试一下不带 `-p` 建两级会怎样？

---

### 步骤 2 · 创建与拷贝（8 分钟）

**做什么**：造两个文件，然后实验 `cp` 的三种形态

```bash
cd /tmp/prj
touch src/main/app.py docs/readme.txt
echo "hello linux" > docs/readme.txt

cp docs/readme.txt backup/          # ① 拷文件
cp -r src backup/                   # ② 拷目录（递归）
cp -r src /tmp/prj2                 # ③ 拷到不存在的新路径
ls -R backup ; ls /tmp/prj2
```

**必须故意犯的错（重要）**：
```bash
cp src /tmp/test1        # 不加 -r 拷目录 → 记录报错原文
```

**预期报错**：`cp: -r not specified; omitting directory 'src'`

**✅ 自检**：`cp` 和 `mv` 对目录的处理规则差异是什么？

---

### 步骤 3 · 移动与改名（8 分钟）★ 本次核心

**做什么**：三种 `mv` 用法 + 那道"批量移动 + 改名"的题

```bash
# ① 改名
mv docs/readme.txt docs/intro.txt

# ② 通配符批量移动
mv docs/*.txt backup/

# ③ ★核心题：把 backup 里的 readme.txt、intro.txt 一起移到 /tmp，
#    并把 readme.txt 改名为 README.md —— 两条命令
mv /tmp/backup/readme.txt /tmp/backup/intro.txt /tmp/
mv /tmp/readme.txt /tmp/README.md

ls /tmp/README.md /tmp/intro.txt
```

**预期输出**：两个路径都存在，无报错

**✅ 自检（这题的答案要能脱口而出）**：为什么必须两条命令？
> 因为 `mv` 的参数模型只有两种形态：单源 → 改名；多源 → 目标必须是目录且全部保持原名。想"批量移动又改其中一个的名字"，等于混用两种形态，`mv` 会拒绝。

---

### 步骤 4 · 打包与解压（8 分钟）

**做什么**：`tar` 打包 → 只看不解 → 解到新目录 → diff 校验完整性

```bash
cd /tmp
tar -czf prj.tar.gz prj/
tar -tf prj.tar.gz                    # 只看清单，不解开
mkdir /tmp/restore
tar -xzf prj.tar.gz -C /tmp/restore
diff -r /tmp/prj /tmp/restore/prj     # 无输出 = 完全一致
ls -lh prj.tar.gz
```

**预期输出**：`diff` 无任何输出；`.tar.gz` 体积只有几 KB

**✅ 自检**：`-czf` 和 `-xzf` 里四个字母分别是什么？`-tf` 为什么不需要 z？

---

### 步骤 5 · 删除（3 分钟）

```bash
rm /tmp/README.md
rm /tmp/prj2              # 不带 -r 删目录 → 记录报错
rm -rf /tmp/prj2          # 带 -r 才能删
ls -d /tmp/prj /tmp/restore/prj           # 原目录还在
ls -d /tmp/prj2 2>&1      # 应该报"没有那个文件或目录"= 删成功了
```

**预期报错（第一种）**：`rm: cannot remove 'prj2': Is a directory`

**✅ 自检**：`rm -rf` 删掉的东西，能从哪恢复？（答案：无处可恢复，除非有备份）

## 附：本次涉及命令速查（做完再看）

| 命令 | 关键点 |
|---|---|
| `mkdir -p` | 递归创建，父目录不存在自动建 |
| `cp -r` | 拷目录必须加；`cp -a` 保留权限时间 |
| `mv` | 同分区=改目录记录（瞬间完成）；跨分区=真复制 |
| `tar -czf` | c 创建 z gzip f 文件名 |
| `tar -xzf -C` | x 解开 C 指定目标目录 |
| `tar -tf` | 只看清单 |
| `rm -rf` | r 递归 f 强制（不问）——最危险的组合 |
| `diff -r` | 递归比较两个目录，无输出=一致 |
